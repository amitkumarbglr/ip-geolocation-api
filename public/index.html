    Try it from the terminal

    # Single lookup
curl https://YOUR-APP.example.com/api/v1/ip/8.8.8.8

# Lookup of the caller's own address
curl https://YOUR-APP.example.com/api/v1/ip/me

# Batch (up to 50)
curl -X POST https://YOUR-APP.example.com/api/v1/ip/batch \
  -H 'content-type: application/json' \
  -d '{"ips":["8.8.8.8","2001:4860:4860::8888"]}'

# AI explanation
curl -X POST https://YOUR-APP.example.com/api/v1/ip/8.8.8.8/explain

    Accuracy is highest at country level and lower for city, mobile, VPN and proxy traffic. Results are not a substitute for a licensed production database.
